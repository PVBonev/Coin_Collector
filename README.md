# 🪙 CoinCollector - Numismatic Collection Manager

Web-based application for managing a personal coin collection. Developed as a university project using the PHP, JS, HTML, CSS.

## 🚀 Features
* **User Authentication:** Secure login system.
* **Dashboard:** Visual overview of the collection (Total coins, Estimated value).
* **Add Coins:** Upload details and photos of new acquisitions.
* **Database:** Relational database storage for persistence.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (Custom Grid Layout, No frameworks).
* **Backend:** PHP 8.0+.
* **Database:** PostgreSQL .
